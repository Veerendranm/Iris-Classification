## 📌 Project Overview

An end-to-end Machine Learning web application that classifies iris flower species (*Setosa*, *Versicolor*, *Virginica*) based on morphological measurements of sepals and petals. The project demonstrates standard multiclass classification workflows, comparative algorithm evaluation, and web deployment.

---

## ✨ Key Features

* **🎯 Multiclass Classification:** Evaluated and optimized across multiple models (Logistic Regression, Decision Trees, K-Nearest Neighbors, SVM) for high precision.
* **⚡ Interactive Prediction Interface:** User-friendly Flask web interface that provides instant species classification from feature inputs.
* **📊 Feature Importance & EDA:** Visual analysis showing clear decision boundaries between sepal/petal dimensions across species.
* **🛠️ Modular ML Pipeline:** Clean separation of dataset ingestion, preprocessing, model serialization (`pickle`/`joblib`), and endpoint serving.

## ⚙️ Quick Start & Installation

### 1. Clone the Repository
```bash
git clone [https://github.com/Veerendranm/iris-classification.git](https://github.com/Veerendranm/iris-classification.git)
cd iris-classification
```
### 2. Set Up Virtual Environment & Dependencies
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```
### 3. Launch Application
```bash
python app.py
```
